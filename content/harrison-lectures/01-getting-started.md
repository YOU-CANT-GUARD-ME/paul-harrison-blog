## Dart가 뭐예요?

Dart는 구글이 만든 프로그래밍 언어예요. **Flutter 앱은 전부 Dart로 만들어요.** 그래서 Flutter를 하고 싶다면 Dart가 첫걸음이에요.

## 코드는 어디서 실행해요?

[DartPad](https://dartpad.dev)를 여세요. 왼쪽에 코드를 쓰고 **Run**을 누르면 오른쪽에 결과가 나와요. 설치할 건 없어요.

> [!note] 나중에 컴퓨터에 설치하고 싶다면
> Flutter SDK를 설치하면 Dart도 같이 설치돼요. 그러면 터미널에서 `dart run 파일이름.dart`로 실행할 수 있어요. 지금은 DartPad로 충분해요.

## 첫 번째 프로그램

DartPad에 있는 코드를 다 지우고 이걸 붙여넣어 보세요.

```dart
void main() {
  print('안녕, Dart!');
}
```

**Run**을 누르면 `안녕, Dart!`가 출력돼요. 한 줄씩 볼게요.

- `main`: 프로그램이 **시작하는 곳**이에요. Dart는 항상 `main`부터 실행해요.
- `void`: 이 함수는 결과값을 돌려주지 않는다는 뜻이에요. (4강에서 자세히 배워요.)
- `{ }`: 중괄호 안이 `main`이 할 일이에요.
- `print(...)`: 괄호 안의 내용을 화면(콘솔)에 출력해요.
- `;`: 문장이 끝날 때마다 **세미콜론**을 붙여요. 빼먹으면 에러가 나요. 처음엔 이걸 제일 많이 까먹어요!

## 주석

주석은 컴퓨터가 무시하는 메모예요. 코드를 설명할 때 써요.

```dart
void main() {
  // 한 줄 주석

  /*
    여러 줄 주석
    이렇게 길게 쓸 수 있어요
  */

  print('주석은 출력되지 않아요');
}
```

## 문자열 안에 값 넣기

문자열은 작은따옴표 `'...'`나 큰따옴표 `"..."`로 감싸요. 문자열 안에 `$`를 쓰면 변수 값을 끼워 넣을 수 있어요.

```dart
void main() {
  var name = '민수';
  var age = 17;

  print('이름: $name');
  print('나이: $age');
  print('내년 나이: ${age + 1}');
}
```

- 변수 하나만 넣을 땐 `$name`
- 계산식을 넣을 땐 `${age + 1}`처럼 중괄호로 감싸요.

> [!tip] 한글을 바로 붙일 때
> `'${name}이에요'`처럼 변수 바로 뒤에 글자를 붙일 땐 중괄호로 감싸 주면 어디까지가 변수인지 확실해져요.

```
내 이름은 해리슨
좋아하는 음식은 떡볶이
```

> [!example]- 정답 보기
> ```dart
> void main() {
>   var name = '해리슨';
>   var food = '떡볶이';
>
>   print('내 이름은 $name');
>   print('좋아하는 음식은 $food');
> }
> ```
